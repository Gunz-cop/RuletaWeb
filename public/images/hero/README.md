# Imágenes del hero

`HomeHero.astro` espera encontrar acá:

- `equipo-decidiendo.jpg` — foto de fondo del hero, full-bleed. Se usa con
  `background-size: cover`, así que cualquier proporción funciona, pero una
  imagen apaisada (16:9 o más ancha) de al menos 1600px de ancho da mejor
  resultado en pantallas grandes.
